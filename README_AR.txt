QUREO AI SOLVER — GOLD EDITION
==============================

المحتويات
---------
- تطبيق Android أصلي بواجهة سوداء وذهبية.
- إنشاء حساب مسؤول لأول تشغيل، وتسمية المسؤول الظاهرة: Egyptian hacker.
- اسم المستخدم يظهر منفصلًا دون إلحاق عبارة Egyptian hacker به.
- إضافة مستخدمين محليين، حظرهم، وإلغاء الحظر، وحذفهم.
- رفع شعار من معرض الهاتف وحفظه داخل مساحة التطبيق.
- فتح موقع QUREO في المتصفح.
- خدمة إمكانية وصول اختيارية لقراءة النص الظاهر في Chrome محليًا فقط.

مهم جدًا — حدود النسخة
----------------------
هذه نسخة أساس Android قابلة للبناء، وليست محرك حل تلقائي متكاملًا.
لا تقوم بتسجيل الدخول إلى QUREO، ولا تحفظ كلمة مرور QUREO، ولا تضغط
على الإجابات أو ترسلها تلقائيًا. لا تتجاوز CAPTCHA أو قيود المنصة.
لا تستخدمها لتقديم إجابات في الاختبارات الرسمية.

خدمة إمكانية الوصول صلاحية حساسة. لا تفعّلها إلا بعد قراءة وصفها وفهمه.
الخدمة مقيدة بمتصفحي Chrome المعروفين، وتقرأ النص الظاهر وتحفظ آخر نص
داخل SharedPreferences محليًا. لا ترسل أي محتوى إلى خادم أو إلى Gemini.

الحسابات في هذه النسخة محلية على الجهاز نفسه، وليست نظام عضويات عبر الإنترنت.
كلمات المرور لا تتم مزامنتها. هذه نسخة أولية وليست مناسبة لتخزين أسرار
حساسة أو لتوزيعها على جمهور قبل مراجعة أمنية مستقلة.

البناء عبر GitHub Actions
-------------------------
1) ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو مخصص.
2) افتح تبويب Actions في المستودع.
3) اختر Build Android APK ثم Run workflow.
4) بعد انتهاء البناء افتح نتيجة التشغيل، ثم Artifacts.
5) نزّل QUREO-AI-SOLVER-GOLD-APK واستخرج app-debug.apk.
6) انقل APK إلى الهاتف وثبّته بعد السماح بالتثبيت من هذا المصدر.

المتطلبات:
- Android Studio/SDK على GitHub runner يتم إعدادها بواسطة workflow.
- Java 17 وGradle 8.9 وAndroid SDK Platform 35.
